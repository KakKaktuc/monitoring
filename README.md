# Мониторинг системы и запись метрик в базу данных

Это приложение позволяет мониторить загруженность системы (CPU, RAM, Disk) и записывать метрики в базу данных MySQL. Также предоставляется возможность просмотра истории записей.

## Требования

Для работы программы необходимо установить следующие компоненты:

- Python 3.8 или выше.
    
- Библиотеки:
    
    - `tkinter` (обычно входит в стандартную библиотеку Python).
        
    - `psutil` (для мониторинга системы).
        
    - `mysql-connector-python` (для работы с базой данных MySQL).
        
- База данных MySQL с таблицей `system_metrics`.
    

---

## Установка и настройка

1. Установите Python с официального сайта: [python.org](https://www.python.org/).
    
2. Установите необходимые библиотеки:
    ```
    pip install psutil mysql-connector-python
    ```
3. Настройте базу данных MySQL:
    
    - Создайте базу данных `desktop_records`.
        
    - Создайте таблицу `system_metrics`:
        
        sql
        
	    ```
        
        CREATE TABLE system_metrics (
            id INT AUTO_INCREMENT PRIMARY KEY,
            cpu_percent FLOAT,
            ram_free FLOAT,
            ram_total FLOAT,
            disk_free FLOAT,
            disk_total FLOAT,
            timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        );
        ```
        
    - Убедитесь, что у вас есть пользователь с доступом к базе данных (например, `desktop` с паролем `1`).

## Использование

1. **Главное окно**:
    
    - Отображает текущую загруженность CPU, RAM и Disk.
        
    - Кнопка "Начать запись" запускает запись метрик в базу данных.
        
    - Кнопка "Остановить запись" останавливает запись.
        
    - Кнопка "Показать историю" открывает окно с историей записей.
        
2. **Окно истории**:
    
    - Отображает все записи из таблицы `system_metrics` в виде таблицы.
